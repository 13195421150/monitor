# Codex 重置监控

从已上线的 SmartKey 会员中心整理出的独立前后端项目，保留黑猫 Logo、动画播报、预计窗口、北京时间重置日历、原帖与时间线，以及展开/收起和中文/原文切换。

## 本地启动

需要 Node.js 20 或更新版本，无需安装第三方运行依赖。

```sh
npm start
```

打开 http://127.0.0.1:4318/monitor 。根地址也会跳转到监控页。动画使用 `/?embed=1&source=auto`，不需要登录或个人 API 密钥。

## 播报判定

- 读取中：保持中性提示，动画揭晓前不显示结果。
- 读取失败、异常数据或失效缓存：显示“数据暂时无法加载”，清除上次播报结果并取消未完成动画。
- 成功读取但没有北京时间当天的已确认公告：显示“暂无已确认的重置公告”。
- 只有成功读取到当天已确认公告，才在动画结束后显示已重置。

播报展示公开公告，个人实际额度以 Codex 账户为准。历史原帖保留原始作者和 X 链接；没有预告不等于没有发生重置。

## 数据和服务器部署

后端通过公开聚合接口获取 Tibo 动态。请求具有 10 分钟持久缓存、ETag、并发合并和 Retry-After 等待，服务启动后自动采集，此后每 10 分钟采集一次。页面不显示聚合站品牌；源码保留真实数据来源，不能据此声称直接抓取 X。

`PORT` 默认 4318，`HOST` 默认 127.0.0.1，`DATA_DIR` 默认项目的 `data/`。部署时把 `DATA_DIR` 指向服务器持久目录。缓存文件为 `reset-feed.json`，仓库不含实际数据。

```sh
PORT=4318 DATA_DIR=/var/lib/codex-monitor node server.mjs
# 或
 docker compose up -d --build
```

运行前确保持久目录可写。Docker 使用独立持久卷，端口只发布到服务器本机，通过自己的 HTTPS 反向代理访问。公开服务仅提供 GET；不包含手动发布后台或本机录制工具。AI 日报侧栏入口保留指向现有线上会员中心，可在部署副本中替换为自己的地址。

## 校验

```sh
npm test
```

覆盖缓存、日期归类、加载/失败/无公告三态、动画取消和恢复。测试数据为构造样本；不携带账户、服务器密码、密钥、用户卡密、缓存或日志。
